# تقارير القبول - كلية الملك فهد الأمنية

موقع HTML عربي خفيف للتقارير التحضيرية المتعلقة بقبول خريجي الثانوية في كلية الملك فهد الأمنية.

## التشغيل

افتح `index.html` في أي متصفح، أو انشر هذا المجلد كمستودع GitHub Pages.

## البنية

- `index.html`: الصفحة الرئيسية وفهرس التقارير.
- `report-01-personal-interview.html`: التقرير الأول عن المقابلة الشخصية.

## إضافة تقرير يومي

1. أنشئ ملفًا بالتسمية `report-YYYY-MM-DD.html`.
2. أضف التاريخ ووسم المصدر لكل معلومة: `رسمي` أو `تجربة متقدم` أو `استنتاج تحضيري`.
3. أضف بطاقة للتقرير في `index.html`.
4. لا تعرض الأسئلة المتداولة باعتبارها أسئلة رسمية ما لم يصدر بها مصدر مباشر موثوق.

## اسم المستودع المقترح
